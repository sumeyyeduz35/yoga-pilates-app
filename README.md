# 🇹🇷 Türkçe

## 📖 Proje Hakkında

Yoga, Pilates ve Reformer disiplinlerini tek bir platformda buluşturan, kullanıcıların kişisel hedeflerine ve deneyim seviyelerine göre egzersiz keşfetmelerini ve gelişimlerini takip etmelerini sağlayan bir mobil uygulamadır.

Uygulama, kişiselleştirilmiş öneriler ve kullanıcı dostu bir arayüz aracılığıyla düzenli egzersiz alışkanlığı oluşturmayı amaçlamaktadır.

Proje aktif olarak geliştirilmektedir.

## ✨ Özellikler

- Kullanıcı kaydı ve kimlik doğrulama
- Kişisel hedeflere ve deneyim seviyesine göre onboarding
- Yoga, Pilates ve Reformer egzersizlerini keşfetme
- Egzersiz arama ve gelişmiş filtreleme
- Kişiselleştirilmiş egzersiz önerileri
- Günün pratiği ve tematik egzersiz koleksiyonları
- Egzersiz programlarını görüntüleme
- Rehberli egzersiz seansları ve ilerleme kaydı
- Günlük takip paneli
- Günlük su tüketimi ve hedef takibi
- Açık ve koyu tema desteği

## 🚀 Kurulum

**Gereksinimler:**

- Node.js
- npm
- Android geliştirme ortamı veya uyumlu bir test cihazı
- Supabase proje yapılandırması

Projeyi klonlayın:

```bash
git clone https://github.com/sumeyyeduz35/yoga-pilates-app.git
cd yoga-pilates-app
```

Bağımlılıkları yükleyin:

```bash
npm install
```

Supabase ortam değişkenlerini kendi geliştirme ortamınız için yapılandırın.

Uygulamayı başlatın:

```bash
npx expo start
```

> Not: Bazı özelliklerin çalışması için Supabase veritabanı ve ilgili servislerin yapılandırılması gereklidir.

## 📖 About the Project

Yoga, Pilates & Reformer is a mobile fitness and wellness application designed to bring three exercise disciplines together in a single platform.

The application helps users discover exercises based on their personal goals, experience levels, and preferences while supporting the development of consistent workout habits.

The project is currently under active development.

## ✨ Features

- User registration and authentication
- Personalized onboarding experience
- Yoga, Pilates, and Reformer exercise discovery
- Exercise search and advanced filtering
- Personalized exercise recommendations
- Daily featured practice and curated collections
- Workout program browsing
- Guided exercise sessions and progress tracking
- Daily wellness tracking dashboard
- Water intake and daily goal tracking
- Light and dark theme support

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React Native | Mobile application development |
| Expo SDK 57 | Development framework |
| TypeScript | Type safety |
| Expo Router | Navigation and routing |
| Supabase | Authentication and database |
| TanStack Query | Server-state management |
| Zustand | Client-state management |
| NativeWind | UI styling |
| ESLint & Prettier | Code quality and formatting |

## 🚀 Getting Started

**Prerequisites:**

- Node.js
- npm
- Android development environment or compatible testing device
- Supabase project configuration

Clone the repository:

```bash
git clone https://github.com/sumeyyeduz35/yoga-pilates-app.git
cd yoga-pilates-app
```

Install dependencies:

```bash
npm install
```

Configure the required Supabase environment variables for your development environment.

Start the development server:

```bash
npx expo start
```

> Note: Some application features require a properly configured Supabase backend and database.
